Pill button, 44px tall at minimum. One **primary** per card or screen section ("Approve roster", "Review and send", "Yes"). **Secondary** for the alternative ("See options", "Choose this roster"). **Quiet** for deferral ("Ask me later", "Not now").

The consumer provides the label, in plain words that say what will happen. A button that sends or records something never says "Submit". Disabled buttons keep their label so the leader knows what is waiting (for example "Approve roster" before every slot has a decision). Icon-only buttons need an `aria-label`.
