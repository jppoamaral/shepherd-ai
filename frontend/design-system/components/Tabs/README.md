Two-segment control for the two roster paths on mobile, with page dots under the swipeable panel. The selected segment is forest with cream text; the unselected one is plain text on sage, so selection reads by fill and by `aria-selected`.

On desktop the tabs disappear and both rosters sit in two columns (`.sh-cols`), each with its own "Choose this roster" button. The consumer provides the labels (the path name, not "Option A") and the panels.
