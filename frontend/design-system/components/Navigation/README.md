Five destinations, in this order: Home, Rosters, People, Memory, Settings. Mobile uses the bottom tab bar (icon above label, 44px targets); desktop uses the left sidebar (240px) with the Shepherd wordmark in `Shepherd` serif on top. The current page is shown by bold text and a sage pill behind the icon, plus `aria-current="page"`, never by color alone.

The ministry switcher sits at the top of the screen (mobile) or under the wordmark (desktop). Show it only when the leader leads more than one ministry; with one ministry, show the ministry name as plain text.
